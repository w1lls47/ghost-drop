Ghost-Drop

Privacy Policy — Effective date: 2026-11-06

Overview

Ghost-Drop is a free, offline desktop utility for Windows. It creates a frameless overlay that lets you stage files for drag-and-drop into other applications. This policy explains what data the application handles, how it is handled, and what leaves your device.

Data collected

Ghost-Drop collects no personal data. The application does not create user accounts, does not require an internet connection, and does not transmit any information to external servers.

Local file handling

When you drag files into the Ghost-Drop overlay, their file paths are held temporarily in memory so they can be re-presented for drag-and-drop into a target application. These paths are never written to disk by Ghost-Drop, never uploaded anywhere, and are discarded when the session ends or the overlay is cleared. No copies of your files are made.

Application state and caching

Ghost-Drop saves minimal preferences (window position, opacity setting) to your local AppData folder using Electron's built-in storage. These values never leave your device. The application does not cache file contents or file metadata beyond the active session.

Telemetry

Ghost-Drop does not include any analytics, crash reporting, or telemetry of any kind. No usage data is collected or transmitted.

Third-party services

Ghost-Drop does not integrate with any third-party service. The optional in-tray "Support FlushTech" link opens your default browser to an external donation page; this is a one-way navigation and no data is sent on your behalf by Ghost-Drop.

Updates

Ghost-Drop does not auto-update. New versions are published as GitHub Releases at github.com/w1lls47/ghost-drop/releases. Downloading an update is entirely voluntary and initiated by the user.

Children

Ghost-Drop is a general-purpose desktop tool and is not directed at children under 13. No age-related data is collected.

Changes
