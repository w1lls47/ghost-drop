Ghost-Drop

Privacy Policy — Effective date: 2026-11-10

Overview

Ghost-Drop is a free, offline desktop utility for Windows. It creates a frameless overlay that lets you stage files for drag-and-drop into other applications. This policy explains what data the application handles, how it is stored locally, and what leaves your device.

Data collected

Ghost-Drop collects no personal data. The application does not create user accounts, does not require an internet connection, and does not transmit any information to external servers.

Local file storage (Shelf)

When you drop a local file, a remote URL, or a browser blob into the Ghost-Drop overlay, Ghost-Drop copies that file to a permanent shelf folder on your device:

%APPDATA%\Ghost-Drop\Shelf\

This copy is kept so that the file remains available for drag-and-drop into target applications even if the original source is closed or unreachable. Shelf files older than 30 days are deleted silently at the next application launch.

The × button on a shelf item removes that item from the visible shelf list within the current session. It does not delete the underlying file from %APPDATA%\Ghost-Drop\Shelf. To permanently delete shelf copies, open that folder in File Explorer and delete the files directly, or allow the 30-day automatic sweep to remove them.

No shelf files are uploaded or transmitted anywhere. All storage is local to your device.

Application preferences

Ghost-Drop saves user preferences (such as window position and opacity) using Electron's built-in storage, also located under your local AppData folder. These values never leave your device.

Remote URL fetching

When you drop a remote URL (from a browser tab, for example) onto the Ghost-Drop overlay, the application makes an outbound HTTP(S) request directly to that URL in order to download the file to your local shelf. This request originates from your device and goes to the host the URL points to. No data is sent to FlushTech or any third party — the request is solely between your device and the URL's host, initiated by your explicit drop action.

Telemetry

Ghost-Drop does not include any analytics, crash reporting, or telemetry of any kind. No usage data is collected or transmitted.

Third-party services

Ghost-Drop does not integrate with any third-party service. The optional in-tray "Support FlushTech" link opens your default browser to an external page; this is a one-way navigation and no data is sent on your behalf by Ghost-Drop.

Updates

Ghost-Drop does not auto-update. New versions are published as GitHub Releases at github.com/w1lls47/ghost-drop/releases. Downloading an update is entirely voluntary and initiated by the user.

Children

Ghost-Drop is a general-purpose desktop tool and is not directed at children under 13. No age-related data is collected.
